SmartRoute Simple Demo

Open index.html in Chrome or another browser. No server or internet connection is required.

Files:
  index.html  - page structure (HTML)
  style.css   - page appearance (CSS)
  script.js   - route selection calculations and interactions (JavaScript)

The original Java project is separate. This website reproduces its demonstration data and formulas in plain JavaScript.

Defense example:
  1. Choose Fastest, budget 6000 KZT, deadline 45 min -> R-02.
  2. Reduce budget to 3625 KZT -> R-03.
  3. Choose Weather-Aware, budget 6000 KZT, deadline 45 min.
  4. Set severity to 0 -> R-02; set severity to 7 -> R-03.

No Java code is executed by this site.
